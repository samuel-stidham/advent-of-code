# advent-of-code

These are **my personal solutions** to the [Advent of Code](https://adventofcode.com/) puzzles. This repository is not open to contributors. I'm not interested in feedback about whether your solution is better, more efficient, or more performant than mine. This is about my own learning journey and growth as a developer.

## About

Advent of Code is an annual series of coding puzzles released each December. I use it as an opportunity to sharpen my problem-solving skills and explore different programming languages. This repo is a record of that journey, meant to show my growth over time, not to be the "best" solution to any given problem.

## Repository Structure

When I add solutions, they will be organized by year, then language, then day:

```text
advent-of-code/
├── README.md
├── 2024/
│   ├── inputs/
│   │   └── day01/
│   │       └── input.txt (not committed)
│   └── go/
│       ├── day01/
│       │   ├── main.go
│       │   └── README.md
│       └── day02/
│           └── ...
├── 2025/
│   ├── inputs/
│   │   └── day01/
│   │       └── input.txt (not committed)
│   ├── go/
│   │   └── day01/
│   ├── python/
│   │   └── day01/
│   │       └── solution.py
│   └── ruby/
│       └── day01/
└── ...
```

Each day's folder typically contains the solution source file(s). Puzzle inputs are fetched locally (and are intentionally not committed). Some days also include a README with notes or thoughts on the problem.
